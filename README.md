# 🌌 Akmalxanv Portfolio

Personal developer portfolio and website for **Abubakr Akmalkhonov**. Built with React 18, Vite, Three.js / React Three Fiber, Tailwind CSS, Framer Motion, and bilingual support (English and Russian), hosted statically on Vercel.

---

## ✨ Features

- **Interactive Visuals**: Interactive 3D desktop model and Earth canvas with Three.js & R3F.
- **Multilingual (i18n)**: Instant runtime switching between English (EN) and Russian (RU).
- **Tabbed Credentials**: Interactive tabbed switcher for Experience, Education, and Certs & Languages.
- **Works Showcase**: Production web applications, GitHub repositories, and direct live demos.
- **Responsive & Modern**: Dark futuristic styling with Tailwind CSS and Framer Motion.

---

## 🚀 Tech Stack

- **Framework**: React 18.2
- **Bundler**: Vite 4.5
- **3D Graphics**: Three.js r154, `@react-three/fiber`, `@react-three/drei`
- **Animations & Interactivity**: Framer Motion 10.13, `react-tilt`
- **Styling**: Tailwind CSS 3.3, PostCSS, Autoprefixer
- **Localization**: `i18next`, `react-i18next`, `i18next-browser-languagedetector`
- **Deployment**: Vercel (Static Frontend)

---

## 🛠️ Development & Build

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Run ESLint validation
npm run lint

# Build for production
npm run build
```
